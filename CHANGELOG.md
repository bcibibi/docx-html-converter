## [1.0.0] - 2026-07-20

### Added

- Initial release
- HTML to DOCX conversion support
- Converters: `b`, `i`, `u`, `strike`, `sub`, `sup`, `span`, `p`, `li`, `ol`, `ul`, `img`, `text`
- CSS color and style parsing
- ESM and CJS dual build output
- `DefaultDocxHtmlFileProvider` for file resolution
